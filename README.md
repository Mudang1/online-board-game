# MuDang: Cat Party Online — 2 โหมด

เกมการ์ด Multiplayer ต้นฉบับ 2–6 คน ภาษาไทย / ห้องส่วนตัว / Socket.IO

## เปิดบน Windows

ใช้ Node.js 20 ขึ้นไป เปิด PowerShell แล้วรัน:

```powershell
cd C:\Users\mudan\mcp-demo-files\online-board-game
npm.cmd install
npm.cmd test
npm.cmd start
```

เปิด http://localhost:3000 หากเซิร์ฟเวอร์เวอร์ชันเดิมยังเปิดอยู่ ให้กด Ctrl+C ที่หน้าต่างเดิมก่อนเริ่มใหม่ แล้วรีเฟรชหน้าเว็บ Ctrl+F5

หากต้องการทดสอบสองผู้เล่น ให้เปิดคนละแท็บแล้วสร้างห้องในแท็บแรก และใส่รหัสห้องในแท็บที่สอง เซสชันใช้ sessionStorage เพื่อแยกที่นั่งแต่ละแท็บ เปิดแท็บใหม่ตามปกติแทนการ Duplicate แท็บที่กำลังเล่น

## การเล่น

- 5 HP และไพ่ 5 ใบต่อผู้เล่น ทุกคนออนไลน์และกดพร้อมก่อน Host เริ่ม
- หนึ่ง Action ต่อเทิร์น เล่นหนึ่งใบหรือผ่าน แล้วจั่วเพื่อจบเทิร์น ภายใน 60 วินาที
- เลือกไพ่โจมตี/แพร่เชื้อ/สลับไพ่ แล้วเลือกเป้าหมายในหน้าต่าง
- เกราะดูดซับดาเมจก่อน HP และอยู่จนใช้หมด เกราะชีวิตกันตายครั้งละหนึ่ง
- ครบ 3 Infection เป็นซอมบี้: ดาเมจโจมตี +1, Tuna Patch ฟื้นเพียง 1 HP และเสีย 1 HP ข้ามเกราะหลังจั่ว ใช้ Antidote Sardine ลดเชื้อต่ำกว่า 3 เพื่อกลับร่าง
- ถือไพ่ได้ 10 ใบ เมื่อเต็ม ทิ้งไพ่เก่าสุดก่อนรับใบใหม่ สำรับหมดสับกองทิ้ง
- หลังเทิร์น 100 เสีย HP เพิ่มอีก 1 ต่อจบเทิร์น เพื่อไม่ให้เกมยืดไม่สิ้นสุด
- ผู้รอดชีวิตคนสุดท้ายชนะ ออกจากห้องระหว่างเล่น = ยอมแพ้

## การเชื่อมต่อ

เซิร์ฟเวอร์รับการเชื่อมต่อบน 0.0.0.0 ผู้เล่นใน Wi-Fi เดียวกันใช้ `http://<IPv4 ของเครื่องเซิร์ฟเวอร์>:3000` และรหัสห้อง ตรวจ IPv4 ด้วย `ipconfig` หาก Windows Firewall ถาม ให้เปิดเฉพาะเครือข่ายที่คุณต้องการใช้งาน

เล่นคนละบ้านต้องมี Node.js hosting ที่รองรับ WebSocket หรือ HTTPS tunnel มายังพอร์ต 3000 โค้ดพร้อมรันเป็นเซิร์ฟเวอร์ แต่ชุดนี้ยังไม่ได้ deploy ไปโฮสต์สาธารณะ และ localhost ไม่ใช่ลิงก์ที่แชร์ให้คนต่างเครือข่ายเข้าได้

กำหนด `PORT` ได้จาก environment ไม่มี API key หรือฐานข้อมูลที่ต้องตั้งค่า

## ข้อมูลและความปลอดภัย

- เซิร์ฟเวอร์ตรวจห้อง ผู้เล่น เทิร์น ไพ่ เป้าหมาย และ Action ก่อนเปลี่ยนผลเกม
- public player UUID แยกจาก secret reconnect token ผู้เล่นรับเฉพาะไพ่ตนเอง
- คำสั่งเล่นแนบ turnNumber ป้องกันคำสั่งเทิร์นเก่า การ์ดหนึ่ง Action ต่อเทิร์น
- reconnect เก็บที่นั่งและมือเดิม เปลี่ยน socket อย่างปลอดภัย และเพิกถอน socket เก่า
- เก็บห้องใน RAM; รีสตาร์ตเซิร์ฟเวอร์ทำให้ห้องหาย ห้องไม่มีคนออนไลน์หมดอายุใน 30 นาที
- ผู้หลุดระหว่างเล่นยังอยู่และหมดเวลาอัตโนมัติ เจ้าของห้องย้ายไปผู้เล่นออนไลน์ และสามารถนำที่นั่งออฟไลน์ออกใน Lobby
- ไม่ใช่ระบบบัญชีหรือ ranked service; ไม่มี persistence ข้าม server restart

## โครงสร้าง

- server.js: HTTP, socket sessions, rate limit, room expiry, timer
- src/game/engine.js: authoritative rules
- src/game/views.js: public/private state
- src/game/cards.js: card definitions + initial deck
- public/: responsive UI + original SVG cat and card artwork
- test/: rules and real six-client Socket.IO integration tests

ภาพการ์ดใหม่ทั้ง 8 ใบเป็น SVG ต้นฉบับ ไม่ใช่ภาพหรือกติกาของ Zombie Kittens ภาพแมวเป็นภาพเวกเตอร์ 2D ที่มีแอนิเมชัน CSS ไม่ใช่โมเดล 3D


## ใหม่: เลือกเล่น Zombie Cats หรือ Boom Cats

ตอนสร้างห้องให้เลือกการ์ดโหมดเกมก่อนใส่ชื่อแล้วกดสร้างห้อง ใน Lobby เจ้าของห้องเปลี่ยนเกมได้ สมาชิกทุกคนจะเห็นโหมดเดียวกันและต้องกดพร้อมใหม่หลังเปลี่ยน จบเกมแล้วกดเล่นอีกครั้งเพื่อกลับ Lobby และเลือกเกมอื่นได้

- Zombie Cats: โหมดเดิม ต่อสู้ด้วย HP/Guard/Infection และร่างซอมบี้
- Boom Cats: โหมดเสี่ยงจั่วแนวปาร์ตี้ที่ได้รับแรงบันดาลใจจากเกมประเภท Exploding Kittens ใช้ชื่อและภาพ MuDang และกติกาประยุกต์ ไม่ใช่เกมทางการ

### Boom Cats

ทุกคนได้ไพ่ปลอดภัย 4 ใบ + Fuse Kit 1 ใบก่อนใส่ Live Wire ลงสำรับจำนวนผู้เล่นลบหนึ่ง เล่น Action ได้ 3 ใบต่อเทิร์นภายใน 60 วินาที แล้วจั่วตามภาระ (ปกติ 1 ใบ)

| การ์ด | ผล |
|---|---|
| Live Wire | จั่วเจอระเบิด ตกรอบเมื่อไม่มี Fuse Kit |
| Fuse Kit | ช่วยชีวิตอัตโนมัติ 1 ครั้งแล้วใช้หมด ระเบิดกลับเข้าตำแหน่งสุ่มในสำรับ |
| Rooftop Hop | ข้ามการจั่ว 1 ใบจากภาระที่ค้าง |
| Double Dare | จบเทิร์น ส่งภาระที่เหลือ +1 ให้คนถัดไป สูงสุด 6 ใบ |
| Night Vision | ดูไพ่บนสุด 3 ใบแบบส่วนตัว ผลดูหายเมื่อสำรับเปลี่ยนหรือจบเทิร์น |
| Alley Mix | สับสำรับที่เหลือใหม่ |
| Sticky Paws | ขโมยไพ่สุ่ม 1 ใบจากเป้าหมาย |

โหมดนี้ไม่ใช้ HP/ซอมบี้ ไม่จำกัดมือที่ 10 ใบ และไม่สับกองทิ้งกลับ เมื่อเวลาหมดเซิร์ฟเวอร์จะจั่วภาระทั้งหมดที่ค้าง หากไม่มีไพ่ให้จั่ว ผู้เล่นนั้นตกรอบ ผู้รอดชีวิตคนสุดท้ายชนะ

รีเฟรชแล้วกลับที่นั่งเดิมได้ หากเจ้าของห้องหลุด ระบบย้ายเจ้าของห้องไปผู้เล่นที่ออนไลน์ ดังนั้นเจ้าของห้องอาจเปลี่ยนหลังรีเฟรช


## ค้นหาห้องและกดจอย

หน้าแรกมีรายการห้องสาธารณะ อัปเดตทุก 5 วินาที ค้นหาจากชื่อเจ้าของห้อง/รหัส กรอง Zombie Cats หรือ Boom Cats และเลือกเฉพาะห้องที่เข้าได้ ใส่ชื่อแมวในช่องด้านบนแล้วกดเข้าร่วมที่การ์ดห้องได้เลย

เมื่อสร้างห้อง ตัวเลือก “แสดงห้องในรายการให้คนอื่นกดเข้าร่วม” เปิดไว้เป็นค่าเริ่มต้นของหน้าเว็บ ถ้าต้องการห้องส่วนตัวให้เอาเครื่องหมายออก เจ้าของห้องเปลี่ยนการแสดงห้องได้ใน Lobby สมาชิกคนอื่นเปลี่ยนไม่ได้ ห้องกำลังเล่น/เต็ม/จบเกมจะแสดงสถานะแต่เข้าร่วมไม่ได้จนเจ้าของห้องกลับ Lobby และมีที่นั่งว่าง ห้องที่ไม่มีผู้เล่นออนไลน์จะไม่แสดง

รายการนี้แสดงห้องที่สร้างบน Node.js server เดียวกันเท่านั้น ทุกคนต้องเปิดเว็บจากเซิร์ฟเวอร์เดียวกัน หากแต่ละคนรัน localhost ของตัวเองจะเป็นคนละเซิร์ฟเวอร์ การเผยแพร่เว็บบนอินเทอร์เน็ตยังต้องมี hosting/tunnel ตามหัวข้อการเชื่อมต่อ
